# CYBER-X SOC Assessment Prototype

A self-contained front-end prototype for **SIH26157 — Supervisory Analytics Tool for SOC Assessment (SAT-SA)**.

It demonstrates the central supervisory workflow:

- SOC effectiveness scoring across detection, investigation, response, and coverage
- correlation of fragmented telemetry into an attack story
- detection-gap identification and prioritized recommendations
- a cyber-risk graph showing affected entities and blast radius
- safe, synthetic SOC Digital Twin replay scenarios

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server. No credentials, data sources, dependencies, or production security actions are included.

## Prototype safety

All incidents, users, assets, risk values, and recommendations are fictional. The containment action is deliberately represented as a human-approval workflow; the prototype does not connect to or affect security systems.
